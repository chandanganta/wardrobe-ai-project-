# Wardrobe AI — Upgraded Frontend

This folder is reserved for the separate React + Vite frontend iteration.

## Planned interface improvements

The supplied upgrade notes describe:
- A responsive occasion carousel with ten occasion choices.
- Click, scroll-wheel, keyboard-arrow and previous/next controls.
- Reduced-motion support.
- An interactive garment rail in My Wardrobe.
- Responsive layout, focus states and hover/press feedback.
- Local browser storage for wardrobe items and saved looks.

## Current status

This is a **scaffold, not a complete runnable frontend yet**. The uploaded project files did not include the required `src/` source tree (including `src/main.jsx`), components, styles and assets. Those files must be added before running a build.

The upgraded UI is described as a frontend prototype. Outfit recommendations use sample data until a real recommendation service is connected.

## Run after the source files are added

```bash
npm install
npm run dev
```

Build and preview:

```bash
npm run build
npm run preview
```

Keep this frontend's dependencies and scripts isolated from the original root-level project.
